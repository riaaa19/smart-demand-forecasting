# Smart Retail Demand Forecasting & Inventory Planner

## Overview
This project uses historical retail sales data (Kaggle Store Sales - Time Series Forecasting dataset) to forecast future product demand and provide actionable inventory recommendations.

## Project Structure
```
smart-demand-forecasting/
├── data/          # Raw and processed datasets
├── notebooks/     # Data exploration & modeling notebooks
├── src/           # Python source modules
├── models/        # Trained ML model artifacts
├── outputs/       # Forecast outputs & reports
└── README.md
```

## Setup & Prerequisites
1. Ensure Python 3.10+ is installed.
2. Activate virtual environment:
   - Windows (PowerShell): `.\.venv\Scripts\Activate.ps1`
3. Place Kaggle Store Sales dataset files inside `data/`.
